# Comment utiliser ce kit (à supprimer ensuite)

1. **Sprint 0** : crée le dépôt `sentinelssh`, puis copie tout le contenu de ce dossier à sa racine.
   Premier commit : `docs: add project documentation and templates`.
2. **Dans GitHub** : crée la branche `develop`, protège `main` (Settings → Branches), crée les labels
   `bug`, `bloquant`, `majeur`, `mineur`, `Must`, `Should`, `Could`, et les milestones Sprint 1 à Sprint 4.
   Les modèles d'issue et de Pull Request s'activent tout seuls grâce au dossier `.github`.
3. **Chaque lundi** : crée les issues du sprint à partir de `docs/sprints/sprint-planning.md`.
4. **Chaque dimanche** : remplis la revue et la rétrospective à partir des modèles `docs/sprints/_modele-*.md`.
5. **Le README décrit l'application telle qu'elle sera à la fin.** Mets-le à jour à chaque sprint : ton SWE
   vérifiera qu'il correspond vraiment au code. Remplace les commentaires « À compléter ».
6. Supprime ce fichier une fois le kit en place.
